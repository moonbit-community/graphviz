# graphviz-cli

`moonbit-community/graphviz-cli` is the native command-line frontend for
`moonbit-community/graphviz`. It owns asynchronous I/O and depends on
`moonbitlang/async`.

From the repository root:

```sh
moon build cli/cmd/dot --target native
moon run cli/cmd/dot --target native -- -Tsvg input.gv -o output.svg
```

- `cli`: option parsing and render orchestration
- `cmd/dot`: executable entrypoint
- `dot/fs`: file loading, UTF-8 decoding, and Latin-1 fallback
- `integration`: layout and renderer tests against shared fixture files

Moon runs this module's tests from this directory. File-based tests use
`../tests/` and `../refs/graphviz/`; initialize the repository's upstream submodule
before running them. No parity fixtures are generated by the implementation
under test.
